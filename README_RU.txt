AuraCam — твой confidence booster
Первая версия для Windows 10 (1809+) / Windows 11, 64-bit, Intel/AMD.

КАК ЗАПУСТИТЬ
1. Скопируй AuraCam-Windows-x64.zip на свой Windows-компьютер.
2. Правой кнопкой по ZIP → «Извлечь всё». Дождись распаковки.
3. Открой получившуюся папку AuraCam и запусти AuraCam.exe.
   Папки app и runtime должны оставаться рядом с EXE.
   Отдельно устанавливать Python, FFmpeg или библиотеки не нужно.
4. Камера включится автоматически. Если Windows спросит доступ — разреши его.
5. Посмотри в камеру, поверни голову, улыбнись или сделай жест.
   После короткого начального буфера движение запустит эдит с музыкой.

КАК ЭТО РАБОТАЕТ
• Зелёная рамка показывает найденное лицо. Это не оценка внешности.
• Детектор реагирует на изменения в области лица и на движение в кадре,
  пока лицо видно. Мимика, поворот головы, рука перед камерой — всё подходит.
• После эдита — пауза 2,5 секунды. Затем новое движение запускает следующий.
• «Микс: я + эдиты» чередует твои эдиты и 3 фрагмента из референса.
• «Только мой эдит» делает каждый эдит из вебки.
• «Только видеоэдиты» включает только встроенные ролики.
• Для твоего эдита используются до 6 последних секунд вебки: приближения,
  стоп-кадр, слоумо, быстрые склейки, дублирование кадра и подпись AURA.
• Музыка запускается вместе с видео. Регулятор «Звук» меняет громкость.
• Последний собственный эдит можно сохранить кнопкой «Сохранить мой эдит»:
  MP4, H.264 + AAC, 640×360, 30 fps, 6 секунд. В экспорт входит музыка.

КНОПКИ
Старт / Стоп — включить или отключить камеру.
Камера 1–4 — выбрать другое устройство; сначала нажми «Стоп».
Чувствительность — вправо, если небольшие движения пропускаются;
                  влево, если срабатывает слишком часто.
Эдит сейчас / Пробел — вручную проверить эдит после заполнения буфера.
F11 — полноэкранный режим.
Escape — выйти из полного экрана; в обычном окне — прервать эдит.

ЕСЛИ КАМЕРА НЕ РАБОТАЕТ
Закрой другие приложения, использующие камеру. Попробуй «Камера 2».
В параметрах Windows проверь разрешение доступа к камере для классических
приложений. Обеспечь свет на лице. Полный профиль, закрытое лицо и очень
слабое освещение могут мешать детектору.
На редакциях Windows N может потребоваться официальный Media Feature Pack.

ЕСЛИ ПРИЛОЖЕНИЕ НЕ ЗАПУСКАЕТСЯ
Проверь, что ZIP распакован целиком, и EXE не вынесен отдельно из папки.
Запусти DIAGNOSTICS.cmd: он проверит библиотеки без включения камеры.
Текст ошибки можно прислать в этот чат.
Логи: %LOCALAPPDATA%\AuraCam\diagnostics.txt, startup-error.txt, auracam.log.

ВИДЕО И ЗВУК
Встроенные ролики и звуковые фрагменты вырезаны из присланного референса
пользователя (TikTok @mundane.mp4). Это фрагменты съёмки экрана, поэтому
они имеют исходные размытие, перспективу и иногда лицо автора референса.
Оригинальные чистые файлы этих эдитов не были предоставлены.
Программа воспроизводит поведение референса, но это не точная копия его
исходного приложения: интерфейс и эффекты собственного эдита реализованы заново.
В папку app\assets\edits можно добавить свои MP4 (лучше H.264/AAC, 3–10 сек).
Удаление встроенных MP4 переключит приложение на собственные эдиты.
Звук своих эдитов: app\assets\sounds\*.wav, желательно 6 секунд.

ФАЙЛЫ И НАСТРОЙКИ
Работа полностью локальная, интернет при запуске не нужен.
Микрофон не используется. Буфер вебки хранится в памяти и очищается при
остановке. Последний собственный эдит остаётся в памяти до закрытия, чтобы
его можно было сохранить. Видео записывается на диск только по кнопке.
Громкость, чувствительность, камера и режим сохраняются в
%LOCALAPPDATA%\AuraCam\settings.ini.

ДЛЯ ПЕРВОГО ВАЙБКОДИНГА
Исходники открыты в папке app — меняй их и перезапускай EXE:
  main.py       — окно, цвета, кнопки, состояние плеера;
  engine.py     — движение, буфер вебки, эффекты собственного эдита;
  camera.py     — получение кадров с камеры;
  media.py      — видео, звуковые дорожки и сохранение MP4.
Например, в engine.py можно поменять надписи +999 AURA, LOCKED IN,
ABSOLUTE CINEMA, длительность паузы cooldown и параметры приближений.
Для тестов: runtime\python.exe -m unittest discover -s app -v

ПРОВЕРЕНО / НЕ ПРОВЕРЕНО
Проверены 5 автоматических тестов логики, интерфейс, детекция лица в очках
на референсе, автосрабатывание на движущемся тестовом видео, воспроизведение
всех 3 клипов, экспорт 6-секундного MP4 со звуком и остановка видеопотока.
Эти проверки выполнены на macOS на тех же версиях Python-библиотек.
Windows-запускатель собран как настоящий PE32+ x64 GUI executable.
Windows-библиотеки и их DLL-зависимости включены и проверены статически.
Запуск EXE на настоящих Windows 10/11 и работу с твоей вебкой проверить здесь
не было возможности. Поэтому это первая сборка для проверки на твоём ПК.

YuNet, imageio-ffmpeg 0.6.0. Лицензии — THIRD_PARTY.txt и dist-info рядом с библиотеками.

https://doc.qt.io/qt-6.8/supported-platforms.html
